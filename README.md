
## 🚀 Как использовать

1.  **Навигация:** Перейдите в нужную директорию с названием предмета.
2.  **Изучение:** Ознакомьтесь с файлами:
    *   `README.md` внутри папки (если есть) — краткое описание раздела.
    *   Файлы с расширением `.md` — чек листы для отработки.

3.  **Поиск:** Используйте поиск по репозиторию (`Ctrl + K` или `Cmd + K` на GitHub) для быстрого нахождения ключевых слов.

## 📝 Как добавить свои материалы

Мы приветствуем вклад в развитие репозитория!

1.  **Создайте новую ветку** или сделайте форк репозитория.
2.  **Добавьте файлы** в соответствующую директорию. Если новой дисциплины нет, создайте папку с её названием (например, `biology/`).
3.  **Придерживайтесь структуры**:
    *   Для лекций используйте папку `lectures/`.
    *   Для задач — `tasks/`.
    *   Для кратких справочников создавайте файлы с суффиксом `_cheatsheet.md`.
4.  **Оформите файлы** в формате Markdown (`.md`) для лучшей читаемости.
5.  **Сделайте Pull Request** с описанием добавленных изменений.
