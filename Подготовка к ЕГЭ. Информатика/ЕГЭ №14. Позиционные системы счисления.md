## Основные алгоритмы решения

### G1. Перевод чисел между системами счисления
Типовая ситуация: дано выражение с числами в разных системах счисления, требуется вычислить результат и записать его в заданном основании.

Порядок решения:
1. Перевести все исходные числа в десятичную систему.
2. Выполнить арифметические действия.
3. Перевести полученный результат в систему счисления, указанную в условии.
4. Проверить правильность перевода.
### G2. Определение основания по количеству разрядов
Типовая ситуация: известно, что число в некоторой системе счисления имеет три цифры. Нужно найти основание.

Порядок решения:
1. Обозначить основание через \(p\).
2. Использовать условие о количестве цифр.
3. Записать двойное неравенство
4. Найти целые значения \(p\), удовлетворяющие неравенству.
5. Если есть дополнительные условия на цифры, проверить их.
### G3. Поиск чисел по последним цифрам
Типовая ситуация: требуется найти все числа, запись которых в системе с заданным основанием заканчивается на определённую последовательность цифр.

Порядок решения:
1. Перевести последние цифры в десятичную систему.
2. Определить количество последних разрядов.
3. Составить остаток от деления
4. Записать общий вид подходящих чисел
5. Найти все значения, удовлетворяющие диапазону из условия.
6. Проверить порядок ответа.
### G4. Подсчёт цифр в диапазоне чисел
Типовая ситуация: нужно посчитать, сколько раз определённая цифра встречается в записи всех чисел заданного диапазона в другой системе счисления.

Порядок решения:
1. Определить границы диапазона.
2. Перевести каждое число в нужную систему.
3. Посчитать количество вхождений искомой цифры.
4. Сложить полученные количества.
### G5. Подсчёт цифр в выражениях с большими степенями
Типовая ситуация: дано выражение с огромными степенями, результат записывают в системе с заданным основанием. Нужно найти количество определённой цифры.

Есть два основных способа.
**Способ 1. Математический анализ**
1. Привести все слагаемые к степеням одного основания.
2. Расположить степени по убыванию.
3. Использовать свойства разностей степеней
4. Определить, какие участки записи формируют максимальные цифры и нули.
5. Посчитать количество нужных цифр.

**Способ 2. Программный перебор цифр**
1. Вычислить значение выражения.
2. Последовательно получать остаток от деления на основание.
3. Сравнивать остаток с искомой цифрой.
4. Увеличивать счётчик.
5. Делить число на основание и повторять до нуля.
### G6. Подсчёт единиц и нулей в двоичной записи
Типовая ситуация: выражение состоит из больших степеней двойки, а требуется найти количество единиц или нулей в двоичной записи.

Порядок решения:
1. Привести все слагаемые к степеням двойки.
2. Расположить степени по убыванию.
3. Учесть, что сложение и вычитание могут менять соседние разряды.
4. Подсчитать единицы.
5. Если требуется количество нулей, найти длину записи и вычесть количество единиц.
### G7. Подбор неизвестной цифры по условию делимости
Типовая ситуация: в нескольких числах в системе с основанием \(p\) неизвестная цифра обозначена через \(x\). Требуется найти минимальное или максимальное значение \(x\), при котором выражение делится на заданное число.

Порядок решения:
1. Определить допустимый диапазон цифры:
2. Перевести выражение в десятичную систему.
3. Выразить его значение через \(x\).
4. Проверить условие делимости
5. Выбрать минимальное или максимальное подходящее значение \(x\).
6. Вычислить требуемое частное.
### G8. Поиск неизвестного основания по арифметическому равенству
Типовая ситуация: дано равенство чисел, записанных в системах счисления с неизвестными основаниями. Требуется определить основание и значения неизвестных цифр.

Порядок решения:
1. Определить минимально возможное основание: оно должно быть больше всех известных цифр.
2. Записать числа через степени оснований.
3. Получить уравнение относительно неизвестных оснований.
4. Использовать дополнительные условия: минимальное основание, максимальное основание, зеркальность оснований и т. д.
5. Перебрать допустимые варианты или решить уравнение.
6. Проверить найденное равенство обратным переводом в десятичную систему.
### G9. Подбор числа по количеству нулей в записи выражения
Типовая ситуация: дано выражение с неизвестным числом \(x\), которое находится в определённом диапазоне. Результат записывается в системе с заданным основанием, а нужно найти максимальное или минимальное \(x\), при котором количество нулей соответствует условию.

Порядок решения:
1. Определить диапазон допустимых значений \(x\).
2. Вычислить значение выражения.
3. Перевести результат в нужную систему счисления.
4. Подсчитать количество нулей.
5. Проверить условие задачи.
6. Сохранить минимальное или максимальное подходящее значение.
### G10. Сложные задачи на свойства записи
Порядок решения:
1. Вычислить или построить запись числа.
2. Определить, что именно требуется подсчитать.
3. Разделить задачу на отдельные проверки.
4. Реализовать подсчёт каждой характеристики.
5. Проверить, что учитывается числовое значение цифры, а не только её символ.

Пример базового алгоритма перевода числа в систему с основанием \(p\):

```
def to_base(n, p):
    digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    result = ""

    while n > 0:
        result = digits[n % p] + result
        n //= p

    return result or "0"
```

Пример подсчёта цифры:

```
number = 123456
base = 7

representation = to_base(number, base)
count = representation.count("3")

print(representation)
print(count)
```

Для оснований больше 10 необходимо помнить, что цифры от 10 до 35 обычно обозначаются буквами A–Z.
