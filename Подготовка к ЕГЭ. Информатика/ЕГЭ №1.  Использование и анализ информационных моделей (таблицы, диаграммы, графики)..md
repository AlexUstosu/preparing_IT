## Краткая теория

### 1. Граф и его представление
- **Граф** — набор вершин и соединяющих их рёбер.
- **Взвешенный граф** — граф, где каждому ребру сопоставлено число (вес): расстояние, стоимость, время.
- **Матрица смежности (весовая матрица)** — таблица, в которой на пересечении строки и столбца указывается вес ребра. Пустая клетка означает отсутствие ребра.

### 2. Степень вершины
- **Степень вершины** — количество рёбер, соединённых с этой вершиной.
- В весовой матрице степень вершины = количество непустых клеток в соответствующей строке (или столбце).

### 3. Симметричность матрицы
- Если матрица симметрична относительно главной диагонали, то граф неориентированный (дороги в обоих направлениях).
- Если не симметрична — граф ориентированный (одностороннее движение).

### 4. Кратчайший путь
- Сумма весов рёбер по маршруту.
- Для поиска используется перебор маршрутов или алгоритм Дейкстры (вручную — построение дерева).

### 5. Расписание
- Для поиска кратчайшего времени прибытия учитывается время вылета, время в пути и время на пересадку (если задано).

## Алгоритмы решения

### G1. Сопоставление графа и таблицы (степени вершин)
1. Подсчитать степени всех вершин на графе.
2. Подсчитать степени всех вершин в таблице.
3. Сопоставить вершины с одинаковыми степенями.
4. Уточнить сопоставление по связям с другими вершинами.

### G2. Определение длины дороги между пунктами
1. Определить номера нужных вершин в таблице (через степени и связи).
2. Найти значение на пересечении соответствующих строки и столбца.

### G3. Поиск кратчайшего пути
1. Построить схему дорог (или использовать таблицу).
2. Перебрать все возможные маршруты из начального пункта в конечный.
3. Для каждого маршрута подсчитать суммарную длину.
4. Выбрать минимальную.
5. При большом числе вариантов — строить дерево маршрутов.

### G4. Задачи на расписание
1. Выписать все рейсы, прибывающие в конечный пункт.
2. Для каждого рейса определить, можно ли успеть на него с учётом пересадки.
3. Рассмотреть варианты с одной и двумя пересадками.
4. Выбрать самое раннее время прибытия.

### G5. Сравнение стоимости маршрута
1. Для каждого варианта маршрута подсчитать суммарную стоимость.
2. Учесть дополнительные условия (время, количество монастырей и т. д.).
3. Выбрать оптимальный вариант.

### G6. Подсчёт количества маршрутов
1. Построить дерево возможных маршрутов.
2. Учесть ограничения (не более одного раза через пункт, минимальное число пунктов).
3. Подсчитать количество подходящих маршрутов.

### G7. Выбор таблицы по условию
1. Для каждой таблицы построить схему дорог.
2. Найти все маршруты между заданными пунктами.
3. Проверить выполнение условия (максимальная/минимальная стоимость).
4. Выбрать подходящую таблицу.

### G8. Задачи с дополнительными условиями
1. Определить вершины по степеням.
2. Использовать дополнительное условие для различения вершин с одинаковыми степенями.
3. Найти нужное значение.

### G9. Задачи с неполными данными
1. Построить граф по звёздочкам.
2. Определить степени вершин.
3. Сопоставить с буквенными обозначениями.

### G10. Социальные сети
1. Построить граф по матрице смежности.
2. Найти нужные связи.
3. Подсчитать суммарное количество сообщений.
