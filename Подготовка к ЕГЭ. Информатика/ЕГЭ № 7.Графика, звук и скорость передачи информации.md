# Краткая теория

## 1. Растровые изображения
Для хранения изображения используется формула: I = N · i, где N — число пикселей, i — глубина цвета в битах на пиксель. Количество пикселей равно произведению ширины на высоту. Число цветов определяется как 2^i. 
### Формулы
Количество пикселей: N=W⋅H
Объём изображения: I=N⋅i
Количество цветов:C= 2^i
## 2. Звук
Для звука объём зависит от частоты дискретизации, глубины кодирования, числа каналов и времени. 
### Формула
I=f⋅r⋅k⋅t, где:
- f — частота дискретизации (Гц),
- r — глубина кодирования (бит),
- k — число каналов (1 — моно, 2 — стерео),
- t — время (с).
## 3. Передача данных

Объём переданной информации равен произведению скорости канала на время передачи. 
### Формула
Q=q⋅t
