##  Краткая теория

## 1. Реляционные базы данных

Реляционная база данных — набор связанных таблиц.
- Поле — столбец таблицы.
- Запись — строка таблицы.
- Первичный ключ (Primary Key) — поле или набор полей, однозначно идентифицирующий запись.
- Внешний ключ (Foreign Key) — поле, связывающее запись одной таблицы с записью другой таблицы.
## 2. Связи между таблицами

Основные типы связей:
- 1:1 — одной записи соответствует одна запись.
- 1:N — одной записи соответствует несколько записей.
- M:N — нескольким записям одной таблицы соответствуют несколько записей другой таблицы; обычно реализуется через промежуточную таблицу.
## 3. Основные операции

|Операция|Назначение|
|---|---|
|COUNT|Подсчёт записей|
|SUM|Суммирование значений|
|AVG|Среднее арифметическое|
|MAX|Максимальное значение|
|MIN|Минимальное значение|
## 4. Вычисляемые поля

Вычисляемые поля позволяют получать значения на основе других столбцов.
Примеры:
- Стоимость товара = количество × цена.
- Масса товара = количество упаковок × масса упаковки.
- Объём товара = количество упаковок × объём упаковки.
- Выручка = сумма стоимости проданных товаров.
## 5. Работа с датами

При работе с датами необходимо:
- учитывать границы периода;
- включать обе граничные даты, если указано «включительно»;
- не путать дату начала и дату окончания операции;
- учитывать год, если в базе присутствуют данные за несколько лет.
