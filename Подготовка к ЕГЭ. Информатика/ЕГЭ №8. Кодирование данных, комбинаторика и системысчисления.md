## Основные алгоритмы решения

### G1. Подсчёт слов с повторениями
Типовая ситуация: есть алфавит из нескольких символов, длина слова задана, символы могут повторяться. Дополнительно требуется, чтобы конкретная буква встречалась ровно один раз, хотя бы один раз или не более заданного количества раз.

Порядок решения:
1. Определить количество вариантов для каждой позиции.
2. Если ограничений нет, использовать правило умножения.
3. Если есть ограничение на количество конкретных букв, выбрать их позиции.
4. Остальные позиции заполнить допустимыми символами.
5. Если есть несколько способов расположения обязательного символа, проследить, чтобы варианты не пересекались.
### G2. Ограничения на позиции символов
Типовая ситуация: первая буква должна быть гласной, последняя — согласной, определённый символ не может стоять на первом месте.

Порядок решения:
1. Разбить слово на позиции.
2. Для каждой позиции определить допустимый набор символов.
3. Перемножить количество вариантов.
4. Если есть дополнительные запреты на сочетания соседних букв, отдельно определить количество запрещённых вариантов.
5. Вычесть запрещённые варианты с учётом возможных пересечений.
### G3. Перестановки с повторениями
Типовая ситуация: необходимо переставить все буквы заданного слова, но некоторые буквы повторяются.

Алгоритм:
1. Посчитать общее количество символов.
2. Определить количество повторений каждой буквы.
3. Рассчитать число уникальных перестановок по формуле
4. Проверить дополнительные ограничения.
5. Если условия сложные, организовать перебор всех перестановок и удалить дубликаты.

Для программного решения в Python используйте `itertools.permutations`, в C++ — `next_permutation()`.
### G4. Запрещённые и обязательные сочетания
Типовая ситуация: запрещено наличие двух одинаковых букв подряд, сочетания «ЬУ», «ЕУ» или другого определённого фрагмента.

Алгоритм:
1. Сначала определить общее количество вариантов.
2. Найти все запрещённые сочетания.
3. Определить, сколько вариантов содержит каждое запрещённое сочетание.
4. Проверить, могут ли запрещённые сочетания возникать одновременно.
5. Вычесть запрещённые варианты, корректно учитывая пересечения.

Для программного перебора удобно проверять наличие подстроки или равенство соседних символов.

### **G5. Поиск номера слова в алфавитном списке**

Типовая ситуация: требуется найти слово на заданной позиции или определить номер заданного слова.

Алгоритм:
1. Выписать алфавит в том порядке, в котором он используется в условии.
2. Заменить символы цифрами от 0 до \(n-1\).
3. Для поиска слова по номеру вычесть единицу из номера.
4. Перевести полученное число в систему счисления с основанием \(n\).
5. Заменить цифры обратно буквами.

Для поиска номера заданного слова:
1. Заменить буквы цифрами.
2. Рассчитать значение полученного числа в системе счисления с основанием \(n\).
3. Прибавить единицу, если нумерация списка начинается с 1.
### G6. Подсчёт чисел в позиционных системах
Типовая ситуация: требуется найти количество чисел заданной длины в системе счисления с ограничениями на цифры.

Алгоритм:
1. Определить основание системы счисления.
2. Выписать допустимые цифры.
3. Отдельно рассмотреть первую позицию: она не может содержать ноль.
4. Для остальных позиций определить количество допустимых вариантов.
5. Учесть ограничения на количество определённых цифр.
6. Рассчитать итоговое количество вариантов.

### G7. Ограничения на чётность и соседство цифр
Типовая ситуация: две чётные или две нечётные цифры не могут стоять рядом; определённая цифра может соседствовать только с цифрами заданной чётности.

Алгоритм:
1. Разделить цифры системы на чётные и нечётные.
2. Определить допустимые переходы между соседними позициями.
3. Отдельно учесть первую позицию.
4. Если задано точное количество цифр определённого типа, учитывать это при подсчёте.
5. При программном решении проверять каждую пару соседних цифр.
### G8. Перестановки с дополнительными условиями
Типовая ситуация: нужно переставить все буквы слова так, чтобы одна буква стояла после другой, ни одна буква не осталась на прежнем месте или определённая пара букв не стояла рядом.

Алгоритм:
1. Найти общее количество перестановок.
2. Определить, какие перестановки нарушают условие.
3. При возможности использовать симметрию или принцип дополнения.
4. Для сложных ограничений использовать полный перебор.
5. Проверить, что повторяющиеся символы не создают дубликаты.
### G9. Сложные ограничения на состав слова
Типовая ситуация: задано количество гласных и согласных, количество повторений определённых букв, обязательные или запрещённые соседства.

Алгоритм:
1. Составить список всех ограничений.
2. Разделить ограничения на позиционные, количественные и соседские.
3. Определить, какие условия можно учесть формулами.
4. Остальные условия реализовать проверкой готовой последовательности.
5. Убедиться, что проверяются все условия одновременно.
### G10. Комбинированный перебор
Это наиболее универсальный способ решения сложных задач.
Алгоритм:
1. Определить алфавит и длину последовательности.
2. Сгенерировать все возможные варианты.
3. Проверить каждое условие задачи.
4. Если вариант подходит, увеличить счётчик.
5. Если требуется найти первое или последнее подходящее слово, учитывать порядок перебора.
6. Если требуется найти номер, дополнительно учитывать правила нумерации и фильтрации.

|Проверка подстроки|`in`, `find()`|`find()`|
|Удаление дубликатов|`set()`|Контейнер `set`|
|Перевод номера в систему счисления|Деление с остатком|Деление с остатком|

**Что важно освоить в первую очередь:**
- Отличать `product` от `permutations`.
- Понимать, когда перестановки создают дубликаты.
- Проверять количество символов и наличие подстрок.
- Правильно учитывать нумерацию с единицы.
- Понимать, почему при увеличении длины слова количество вариантов резко растёт.

Для C++ отдельно стоит отработать `next_permutation()`: перед использованием последовательность нужно отсортировать, а сам перебор обычно организуют через `do-while`.
